Laminara запускает Minecraft со своими сборками. Сервер собирает готовый клиент любой версии и любого загрузчика, подписывает его и раздаёт. Лаунчер у игрока сверяет подпись, докачивает недостающие файлы и запускает игру. Аккаунты при этом остаются в вашей базе — Laminara обращается к ним через адаптер и никогда не хранит чужие пароли.

Смысл в том, чтобы админ ничего не собирал руками. Он не ходит к Mojang, не запускает установщик Forge, не подбирает версию Java. Всю подготовку сервер делает один раз, а клиент потом лишь синхронизирует файлы по манифесту.

## Из чего состоит

**Сервер** — один бинарник под Linux. Работает как демон, а управляется той же командой: `laminara-server console` подключается к запущенному процессу через Unix-сокет и даёт живые логи и команды.

**Хранилище** держит файлы по содержимому (content-addressed): два одинаковых файла лежат на диске один раз, изменённое докачивается, неизменное берётся из кеша. Отсюда быстрый первый запуск и почти мгновенные обновления.

**Адаптеры** подключают внешние системы через конфиг, а не через правку кода. Источник аккаунтов, хранилище файлов, источник скинов — всё это точки расширения. Нужен новый вариант — добавляется один файл, остальное остаётся как есть.

**Подпись.** Каждый манифест сборки подписан ключом Ed25519. Лаунчер доверяет файлам по подписи, а не по тому, откуда они пришли, — поэтому раздавать байты можно с любого зеркала или CDN, не считая их доверенными.

**Лаунчер** — десктопное приложение на Tauri (Rust + React) под Windows, macOS и Linux. Оператор [собирает его под свой проект](/launcher/building): адрес сервера, ключи и оформление записываются в файл при сборке, поэтому игрок ничего не настраивает.
