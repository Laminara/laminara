Здесь вы запустите сервер, соберёте клиент 1.21.1 с NeoForge и опубликуете его. Большая часть времени уйдёт на скачивание Minecraft и Java, самих команд немного.

<Aside type="note">
Ставить Java вручную не нужно. Для сборок с Forge или NeoForge сервер сам скачивает нужную версию JDK и прогоняет установщик загрузчика.
</Aside>

## Что понадобится

- Linux — сервер работает только на нём.
- Docker (либо Go 1.26+, если собираете из исходников).
- Redis для сессий. В примере он поднимается вместе с сервером.

## Запуск сервера

Самый быстрый путь — установщик. Он скачает сервер, интерактивно расспросит про хранилище, аутентификацию и домен, сгенерирует конфиг с ключами и по желанию поставит systemd-сервис или поднимет Docker-стек:

```sh
curl -fsSL https://raw.githubusercontent.com/MrLeonardosMi/Laminara/main/install.sh | bash
```

Руками качать библиотеки и писать конфиг не нужно — всё соберётся из ответов. Если хотите собрать вручную (Docker, systemd, из исходников) — см. [Установку](/server/install).

```sh
laminara-server status
```

## Первая сборка

Проще всего — через [интерактивную консоль](/console): `laminara-server console`, клавиша **i**, и мастер сам спросит версию, загрузчик и имя, а прогресс покажет вживую. Ниже — те же шаги командами через `exec`: вывод и код возврата пробрасываются, так что их удобно класть в скрипты.

<Steps>

1. **Найдите версию**

   ```sh
   laminara-server exec versions 1.21
   ```
   Выведет релизы и снапшоты, подходящие под запрос.

2. **Посмотрите загрузчики**

   ```sh
   laminara-server exec loaders 1.21.1
   ```
   Для 1.21.1 покажет vanilla, fabric, quilt, forge и neoforge с их актуальными версиями. Для версии, где загрузчика ещё нет, он в списке не появится.

3. **Соберите клиент**

   ```sh
   laminara-server exec install survival 1.21.1 loader=neoforge
   ```
   Сервер скачает Minecraft, библиотеки и Java, прогонит установщик NeoForge и сложит готовый профиль в `build.profilesDir/survival`. Файлы профиля лежат россыпью и их можно править — например, заменить библиотеку на свою сборку.

4. **Опубликуйте**

   ```sh
   laminara-server exec publish survival
   ```
   Профиль превращается в подписанный манифест. Именно его запрашивает лаунчер.

</Steps>

<Aside type="tip">
Готово. `install` собрал клиент, `publish` его подписал. Дальше стоит настроить [аутентификацию](/auth/adapters) и вынести сервер [в продакшен за nginx](/server/production).
</Aside>
