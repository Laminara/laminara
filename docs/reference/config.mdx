Сервер читает один JSON-файл (флаг `--config`). Разделы независимы: работает тот, что описан. Обзор и примеры — в разделе [Конфигурация](/server/configuration).

## auth

<ParamField path="provider" type="string" required>`jsonfile`, `sql` или `http`.</ParamField>
<ParamField path="config" type="object" required>Настройки выбранного провайдера (см. ниже).</ParamField>
<ParamField path="sessions.backend" type="string">`memory` или `redis`.</ParamField>
<ParamField path="sessions.redisAddr" type="string">Адрес Redis при `backend: redis`.</ParamField>
<ParamField path="accessTTL" type="duration">Время жизни токена доступа, например `15m`.</ParamField>
<ParamField path="refreshTTL" type="duration">Время жизни токена обновления, например `720h`.</ParamField>

Поля `config` по провайдерам:

- **jsonfile** — `path`, `hash`, `fields{username, password, uuid}`
- **sql** — `driver`, `dsn`, `table`, `hash`, `fields{username, password, uuid}`
- **http** — `url`, `usernameField`, `passwordField`, `uuidField`, `successField`

Значения `hash`: `argon2id`, `bcrypt`, `sha256`, `sha512`, `md5`, `plain`. Подробнее — [Аутентификация](/auth/adapters).

<ParamField path="config.query" type="string">Для `sql`: свой запрос вместо `table`/`fields`, когда нужна связка таблиц или учёт флага бана. Логин — единственный подстановочный знак, выбираются пароль и (необязательно) UUID.</ParamField>

## rateLimit

Включён по умолчанию: публичный вход, открытый для перебора паролей, — не то состояние,
которое кто-то выбирает осознанно.

<ParamField path="disabled" type="boolean">Выключить все бюджеты. Только для сервера, недоступного из интернета.</ParamField>
<ParamField path="backend" type="string">`memory` (по умолчанию) или `redis` — общий счётчик на несколько экземпляров.</ParamField>
<ParamField path="redisAddr" type="string">Адрес Redis для `backend: redis`.</ParamField>
<ParamField path="login" type="object">Бюджет на один адрес: `{ "limit": 10, "per": "5m" }`.</ParamField>
<ParamField path="account" type="object">Бюджет на один ник, намеренно щедрый: `{ "limit": 50, "per": "15m" }`. Жёсткий лимит здесь дал бы любому способ заблокировать конкретного игрока чужими неудачными попытками.</ParamField>
<ParamField path="challenge" type="object">Бюджет на запросы nonce: `{ "limit": 60, "per": "1m" }`.</ParamField>

Тратится только **неудачная** попытка входа: игрок, который вводит пароль верно, в счётчики
не попадает вообще.
