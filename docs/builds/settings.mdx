Рядом с профилем `install` кладёт файл `laminara.settings.json` — политику сборки, которую задаёт **оператор на сервере**. Игрок её не видит и не может изменить: она уезжает внутри подписанного манифеста, так что подделать нельзя.

```json laminara.settings.json
{
  "userWritable": ["options.txt", "config/", "saves/", "screenshots/"],
  "enforced": ["config/anticheat/**"],
  "serverAddress": "play.example.net"
}
```

Файл предзаполняется при подготовке сборки разумными значениями — правьте его под свою сборку и снова публикуйте.

## Три класса файлов

Каждый файл сборки попадает ровно в один класс. Приоритет — **`enforced` → `userWritable` → обычный**.

<CardGroup cols={3}>
  <Card title="userWritable" icon="pen">
    Игрок волен менять. Лаунчер не проверяет, не перезаписывает и не удаляет такие файлы — правки переживают обновления.
  </Card>
  <Card title="enforced" icon="lock">
    Всегда возвращаются к опубликованному виду — даже правку того же размера лаунчер откатит. Ваши ассеты, форс-настройки.
  </Card>
  <Card title="обычный" icon="cube">
    Всё, что не в списках. Проверяется по хешу, восстанавливается при расхождении, удаляется, если ушло из манифеста.
  </Card>
</CardGroup>

Приоритет `enforced` над `userWritable` позволяет открыть игроку целую папку, но запереть внутри неё поддерево: `userWritable: ["config/"]`, `enforced: ["config/anticheat/**"]`.

## Синтаксис путей

Пути — от корня сборки, через `/`. Язык шаблонов намеренно скупой, чтобы список случайно не «расширился»:

| Шаблон | Что совпадает |
| --- | --- |
| `options.txt` | ровно этот файл |
| `config/` | вся папка `config` и всё под ней |
| `screenshots/*.png` | `.png` прямо в папке (не глубже) |
| `**/*.log` | любой `.log` на любой глубине |
| `config/anticheat/**` | всё поддерево `config/anticheat` |

`*` не пересекает `/`, `**` — это целый сегмент пути. Всё остальное — буквально.

## Адрес сервера

`serverAddress` (`host` или `host:port`, порт по умолчанию `25565`) — адрес игрового сервера этой сборки. Лаунчер пингует его по протоколу Minecraft и показывает **живой онлайн** игроков: по каждой сборке и суммарно по проекту. Поле необязательное; без него счётчик просто не показывается.

## Правила для оператора

<Warning>
Любой файл, который **игра или мод пишет во время работы** (`options.txt`, `config/`, `saves/`, логи, кеши карт), обязан быть в `userWritable`. Иначе лаунчер держит его только для чтения, и игра упадёт с ошибкой записи. Даже если вы поставляете дефолт — это всё равно `userWritable`.
</Warning>

Publish не даст добавить в `userWritable` то, что ломает запуск: `mods/`, `libraries/`, `versions/`, рантайм Java, `assets/` и корневые `.jar`. Незаверяемый и необновляемый мод — это дыра, поэтому такая публикация отклоняется.

<Note>
`enforced` — **не античит**. Подпись Ed25519 гарантирует подлинность того, что вы опубликовали, а `enforced` — честную доставку этого честному игроку и защиту от случайной порчи конфигов. Пропатченный клиент обойдёт любую клиентскую проверку; настоящий античит живёт на игровом сервере.
</Note>
