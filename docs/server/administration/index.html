Удалённое управление

CLI и TUI используют один AdminService. Локально он доступен через Unix-сокет. Сетевой слушатель выключен, пока не задан admin.addr:

TLS требует сертификат с именем сервера, которому доверяет клиент. Для собственного CA передайте --admin-ca-file. Проверку сертификата отключить нельзя. HTTP разрешается только на числовом loopback-адресе и с allowInsecureLoopback: true; этот режим подходит для защищённого туннеля или локального прокси.

Первый токен

До первого запуска создайте хранилище токенов и отдельный файл с токеном:

Оба файла создаются с правами 0600. Bootstrap отказывается перезаписывать существующее хранилище. На работающем сервере токены можно выдавать через локальный сокет:

create возвращает JSON с полем token. Сохраните его в защищённом файле или секретах CI. Сервер хранит только SHA-256 хеш токена; повторно получить секрет через list нельзя. Команды с секретным выводом выполняются через exec, без журнала фонового задания.

Альтернатива файлу — LAMINARA_ADMIN_TOKEN. URL и CA также задаются через --admin-url, --admin-ca-file или LAMINARA_ADMIN_CA_FILE. Токен не передаётся в URL. settings --config ... явно редактирует локальный файл, даже при заданном удалённом адресе.

Права

Для CLI/TUI добавляйте read: клиент запрашивает состояние и возможности сервера.

ПравоОперации
readСостояние, список команд, сборок, игроков и настройки с замаскированными секретами
logsОбщий журнал сервера
settingsИзменение настроек сервера
buildsInstall, publish, delete, настройки сборок, загрузка файлов, apply и rollback
accountsУправление аккаунтами и проверка входа через auth
accessДоступ к сборкам, HWID, машины и баны
signingКлючи подписи
lifecycleDoctor, restart, stop и update
modulesКоманда управления модулями, если она зарегистрирована
command:NAMEОдна зарегистрированная команда, включая её алиасы
adminВсе операции, выдача токенов и команды модулей

Неизвестные команды требуют admin либо явного command:NAME; одного read недостаточно. Команды модулей проходят ту же проверку registry. Команды веб-консоли можно разрешить по имени из exec help. Утилиты установки systemd и резервного копирования остаются локальными командами хоста. Отзыв токена закрывает поток и отменяет его задания не позднее следующей проверки, которая выполняется каждые две секунды.

Долгие операции

Обычные exec и команды TUI автоматически используют задания, если сервер их поддерживает. Команда сообщает ID. Отключение клиента прекращает чтение, сама работа продолжается.

Повтор с тем же ключом, владельцем и аргументами возвращает прежнее задание. Другие аргументы с этим ключом дают ошибку. Новый запуск после ошибки требует нового ключа. После перезапуска незавершённая работа становится interrupted и сама не повторяется. Журнал читает владелец или admin; одновременно выполняются до четырёх заданий. Вывод ограничен 8 МиБ, обрезание отмечается в outputTruncated. Итоговый код сохраняется. История ограничена 10000 заданиями. Архивировать её следует при остановленном сервере, перенося вместе файлы ID.json и ID.events; после удаления записи её ключ можно использовать заново.

Аудит содержит ID токена, имя операции и результат. Аргументы, пароли и новые токены не попадают в общий журнал. Внутри пользовательского вывода несекретной команды могут быть чувствительные данные: каталог заданий доступен только владельцу процесса.

Kubernetes

Смонтируйте TLS Secret через extraVolumes и extraVolumeMounts, задайте config.admin и включите adminService.enabled. Порт Service должен совпадать с admin.addr. Административный Service — отдельный ClusterIP; публичный Ingress его не открывает. Доступ из CI организуется через вашу закрытую сеть или туннель.
