Версии сервера выходят релизами на GitHub. В каждом релизе лежат готовые файлы под Linux
(`amd64` и `arm64`) и `checksums.txt` с их хешами. Тем же путём сервер ставит [установщик](/server/install),
поэтому обновление ничем не отличается от первой установки — меняется только один файл.

## Посмотреть, есть ли новая версия

```sh
laminara-server version          # что установлено сейчас
laminara-server update --check   # что лежит в релизах
```

Раз в сутки сервер смотрит релизы сам и пишет в лог, когда выходит версия свежее:

```
вышла новая версия сервера версия=0.2.0 установлена=0.1.0 поставить=laminara-server update
```

## Поставить

```sh
sudo laminara-server update
sudo systemctl restart laminara-server
```

Команда скачивает файл под вашу систему, сверяет его хеш с `checksums.txt` из релиза и спрашивает
у скачанного файла его версию — если он представляется не тем, чем обещал релиз, обновление
отменяется и на диске ничего не меняется. Прежний файл остаётся рядом как `laminara-server.old`,
так что откатиться можно вручную одной командой `mv`.

<Aside type="caution">
  Замена файла не трогает уже запущенный сервер: новая версия заработает только после перезапуска.
  Пока перезапуска не было, `laminara-server version` показывает старый номер — это не ошибка.
</Aside>

Обновление меняет права на файл, поэтому запускать его нужно от того пользователя, которому файл
принадлежит. Если сервер лежит в `/usr/local/bin`, это `sudo`.

## Настройки

```json
{
  "update": {
    "check": true,
    "install": false,
    "repo": "MrLeonardosMi/Laminara",
    "interval": "24h"
  }
}
```

| Поле | Что делает |
| --- | --- |
| `check` | Смотреть релизы раз в `interval` и писать в лог, если вышла версия свежее. По умолчанию включено. |
| `install` | Ставить новую версию самому и перезапускаться. По умолчанию выключено. |
| `repo` | Репозиторий на GitHub в виде «владелец/имя». |
| `interval` | Как часто смотреть релизы. |

Выключенный `check` означает, что сервер не ходит на GitHub вовсе — ни одного запроса без вашей
команды. Те же поля правятся в консоли: `settings`, раздел «Обновление сервера».

<Aside type="caution">
  `install` включают, когда простой сервера дешевле, чем отставшая версия: сервер перезапустится
  в тот момент, когда выйдет релиз, и выкинет из игры всех, кто был онлайн.
</Aside>
